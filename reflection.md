# Static Code Analysis – Reflection

## 1. What did you learn from static code analysis?
I learned that static code analysis tools help find code quality, formatting, and security problems without running the program.

## 2. What issues did you find in your program?
I found hardcoded secrets, unsafe XML parsing, weak encryption, poor formatting, and naming and documentation problems.

## 3. How did you fix the issues?
I documented the issues, improved the code formatting and naming, and worked on fixing the security and code quality problems using Pylint, Bandit, and Flake8.

## 4. Why is static code analysis important?
Static code analysis helps developers find problems early, improve code quality, and make programs safer and easier to maintain.
